Document Redesign

Modernised document page templates for the staff intranet.

Role
Designer
Team
Product owners, Developers
Tools
Figma, Squiz CMS, HTML, CSS

Overview

The university was migrating its site and separating internal pages from external facing ones. I used the opportunity to refresh the document design templates.

The problem

The existing document page template was outdated. It had repetitive, unnecessary menus and a long, uncategorised list of documents that was hard to navigate, and the design felt fragmented and inconsistent.

Scope of work

  • Mapped the information architecture and user workflows
  • Designed high-fidelity mockups in Figma and iterated on them through feedback
  • Built page templates in Squiz using HTML and CSS
  • Collaborated with the lead developer to address technical constraints
  • Applied GDS design principles for clarity and accessibility

Define

Problem statement

The document pages has an outdated and inefficient design.

Goals

Modernise the pages and improve user experience when navigating back and forth between content.

Success metrics

Positive feedback from internal staff and fewer queries about finding and navigating pages.

Design development

For the design development of the document cover page, it was important to include the essential information including the document's meta data, owners, faculties its sits under, tags and ensuring that the access permission for the document was clear.

Key decisions

  • Replaced navigation menu beside the file listing with a link back to the parent page (faculty/directorate) reducing information overload
  • Document metadata moved higher with the parent page link, keeping the essential information in view
  • Added a permission status bar and pill label for users to identify easily whether the document is public or restricted
  • Updated the listing style to align with the rest of the portal
